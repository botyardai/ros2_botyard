# Introduction 

实现dexhand_controller控制器，实现对指尖力(tactiles)、关节的位置/速度/力矩的统一控制。

## 手势结束后的控制交接

Jazzy 硬件接口在 `doGesture` 成功结束后，将驱动最后成功下发的关节位置、速度、力矩和指尖力目标同步到普通命令接口，再恢复 TOPIC 控制。分批下发的关节命令按关节合并；控制器在手势接单时清除旧 topic 缓存，因此不会在结束后重发动作前的位置。同步在控制循环内完成，不额外发布 `~/commands` 消息；收到新的 topic 命令后正常覆盖同步值。

取消、超时或失败时不会重发旧运动目标，普通控制等待新的有效命令。无有效目标的关节不按零位置下发；显式零速度会保留。

## dexhand_controller

基于forward_controllers_base实现一个简单的控制器，类似forward_command_controller, 但允许向topic同时发送关节的位置/速度/力矩、指尖力指令，进而控制灵巧手运动和抓握。

# 目标值顺序与dexhand_bringup/config/dexhand_controller.yaml的joints和interface_names，tactiles配置一致

# 1. 只发送位置
$ ros2 topic pub --once /dexhand_controller/commands std_msgs/msg/Float64MultiArray "{
  data: [
    0.2618, 0.0,                    # FAJ3, FAJ1 (rad ,  rad)
    0.2618, 0.2618, 0.5236, 0.5236, # THJ4-1 (15°, 15°, 30°, 30°)
    0.0, 0.5236, 1.0472,            # FFJ4-2 (0°, 30°, 60°)
    0.0, 0.5236, 1.0472,            # MFJ4-2 (0°, 30°, 60°)
    0.0, 0.5236, 1.0472,            # RFJ4-2 (0°, 30°, 60°)
    0.0, 0.5236, 1.0472,            # LFJ4-2 (0°, 30°, 60°)
